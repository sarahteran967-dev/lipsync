Arquitectura de Lipsync Modular en JavaScript

Demostraciones interactivas desacopladas de GPU. Sin consumo de tokens ni servidores en la nube.

Nivel 1: Títere Reactivo (RMS)

Mapeo binario de 2 estados (boca abierta / boca cerrada) calibrado por umbral de volumen (Noise Gate).

  • Tecnología: Web Audio API (Analizador RMS)
  • Assets: 2 Sprites PNG + Audio limpio
  • Carga computacional: ~0.5% CPU

Nivel 2: Visemas Fonéticos (FFT)

Detección de formantes espectrales para modular vocales (A, E, I, O, U) en tiempo real sin deformar el set.

  • Tecnología: Transformada Rápida de Fourier (FFT)
  • Assets: 5 Sprites de visemas desacoplados
  • Carga computacional: ~1.0% CPU
